# Computer Vision and Deep Learning Coursework

NCKU Computer Vision and Deep Learning coursework (2025 Fall).

## Selected work

- **[MNIST activation comparison with LeNet-5](HW2/Hw2_1/README.md):** PyTorch implementation comparing Sigmoid and ReLU, training-only rotation augmentation, a fixed training/validation split, and final test evaluation after validation-based checkpoint selection.
- **[Interactive image processing](HW1/):** Python, OpenCV and PyQt5 exercises covering color processing, filtering, edge detection, geometric transformations and thresholding.

`HW2/Hw2_2/` currently contains empty placeholders; it is not a completed classifier.

The original committed HW2 weights and plots were selected using the official MNIST test split as validation. They are historical coursework artifacts, not results of the corrected evaluation. See the HW2 README for the updated protocol and separately recorded rerun results.
